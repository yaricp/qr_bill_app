# API Endpoints

This document provides a description of all the endpoints in the API.

## Bills

*   **GET /bills** - Get a list of all bills.
*   **GET /bills/{bill_id}** - Get a specific bill.
*   **POST /bills** - Create a new bill.
*   **PUT /bills/{bill_id}** - Update a bill.
*   **DELETE /bills/{bill_id}** - Delete a bill.
