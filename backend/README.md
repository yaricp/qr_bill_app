# Backend Services

This directory contains all the backend services for the QR Bill application, including the REST API and the Telegram bot. It is structured to separate different functionalities and allow for independent development and deployment of each service.

## Project Structure

- [**grpc_proto/**](/files/Projects/qr_bill_app/backend/grpc_proto/README.md): Defines the Protocol Buffers for gRPC communication between services.
- [**rest_api/**](/files/Projects/qr_bill_app/backend/rest_api/README.md): Implements the FastAPI-based RESTful API for the application.
- [**tg_bot/**](/files/Projects/qr_bill_app/backend/tg_bot/README.md): Contains the Telegram bot implementation.

## Getting Started

Refer to the specific README files for each backend service for detailed setup and running instructions.
