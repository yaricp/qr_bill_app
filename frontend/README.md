# Frontend

The frontend of the QR Bill App is a web-based application that allows users to generate and manage bills with QR codes.

## Project Structure

The frontend is organized into the following directories:

- **src:** Contains the source code for the frontend, including the components, pages, and styles.
- **public:** Contains the public assets for the frontend, such as the `index.html` file and the favicon.
- **tests:** Contains unit and integration tests for the frontend.

## Getting Started

To get started with the frontend, you'll need to have Node.js and npm installed. Then, you can run the following command to install the dependencies:

`npm install`

Once the dependencies are installed, you can run the following command to start the frontend:

`npm start`

This will start the frontend on `http://localhost:3000`.

## Communication with the Backend

The frontend communicates with the backend using a RESTful API. The API is documented using the OpenAPI specification, which can be found at `/openapi/openapi.json`.
